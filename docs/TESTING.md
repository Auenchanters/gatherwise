# Testing

`npm run verify` runs lint, type-checking, the unit and component tests with coverage, knip, the production build (with its bundle and runtime checks) and the Prettier check. At this commit it runs 1,358 Vitest tests, and every measured file is at 100% statements, branches, functions and lines. CI (`.github/workflows/ci.yml`) runs `npm run verify`, then the Playwright journeys and `npm audit`.

## Coverage

Coverage is collected by `@vitest/coverage-v8` as configured in `vitest.config.ts`:

- **Measured:** `src/domain/**`, `src/shared/**`, `src/features/**/*.ts`, every `.tsx` component under `src/` and `server/**`.
- **Excluded:** Vitest's default exclusions, `**/*.d.ts` (ambient declarations compile to nothing) and `src/main.tsx`.
- **Thresholds** (the run fails below them): lines 95%, statements 95%, functions 95%, branches 90%. The code is at 100% on all four at this commit; the thresholds are the floor, not the target.
- **At this commit** (`npm run test:coverage`, 71 files fully covered): statements 100% (1804 of 1804), branches 100% (946 of 946), functions 100% (570 of 570), lines 100% (1555 of 1555). No coverage-ignore comments are used anywhere; a branch is either reached by a test or the code that made it is gone.

What is outside the measured scope, and why:

- **`src/main.tsx`.** It finds `#root` and renders `<App />` in `StrictMode`, which needs a real page. Every Playwright journey loads it through the production build, and `App` itself is measured through `tests/ui/app.test.tsx`.
- **`api/plan.ts` and `api/health.ts`.** Each is two statements: import the shared handler and export it. The handler is measured in full, and the runtime smoke imports the emitted entry points after every build.
- **`scripts/`.** `scripts/bundle-budget.mjs` and `scripts/runtime-smoke.mjs` run inside every build. `scripts/live-checks.ts` and `scripts/doc-checks.ts` are unit-tested but sit outside `src` and `server`. `scripts/preflight.mjs`, `scripts/live-smoke.ts` and `scripts/dev-server.ts` are thin wrappers run by hand.

## Running each layer

| What                                               | Command                                                          |
| -------------------------------------------------- | ---------------------------------------------------------------- |
| Everything CI runs before E2E                      | `npm run verify`                                                 |
| Unit and component tests                           | `npm test`                                                       |
| One project only                                   | `npx vitest run --project unit` or `npx vitest run --project ui` |
| With coverage and thresholds                       | `npm run test:coverage`                                          |
| End to end (builds, then serves on 127.0.0.1:4173) | `npx playwright install chromium`, then `npm run test:e2e`       |
| End to end with an installed Chrome                | `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`                     |
| End to end against a deployment                    | `E2E_BASE_URL=https://… npm run test:e2e`                        |
| Bundle budget on an existing build                 | `npm run test:bundle`                                            |
| Runtime smoke on an existing API build             | `npm run build:api && npm run test:runtime`                      |
| Live smoke (one real model call)                   | `E2E_BASE_URL=https://… npm run test:live`                       |
| Pre-publish checks                                 | `npm run preflight`                                              |
